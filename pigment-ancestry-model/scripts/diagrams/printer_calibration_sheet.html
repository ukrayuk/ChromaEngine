Printer calibration check sheet — Pigment Ancestry Model

No colorimeter in use — this is an eye-based check, not a numeric profile. Print this page at 100% / actual size (not "fit to page" or "shrink to fit"). Turn off any automatic photo enhancement / vivid colour / colour boost setting in the print driver — you want the most literal, unmodified reproduction of the file, not the printer’s idea of a nicer photo. If your print software offers a colour management choice, try "No colour management" / "Let printer manage colours" first — the model’s hex values are plain sRGB, nothing in them expects an aggressive print-side transform. Compare under consistent, neutral light — daylight from a window or a daylight-balanced lamp (~5000-6500K), not warm incandescent bulbs, which will push everything yellow/orange regardless of the printer.

1. The six anchor pencils — the real ground truth

Hold each real pencil directly against its printed swatch below, in the same light, touching if possible. This is the single most reliable check available without an instrument: these hex values were measured FROM these exact physical pencils, so if a printed swatch looks off from its own real pencil, that tells you the direction and rough size of your printer’s shift at that part of the colour wheel. Note what you see (e.g. "Cool Blue prints a bit more purple / less saturated than the real pencil") — even a rough by-eye note is useful, and the same bias likely applies to the printed arc ladders too.

2. Neutral grey ramp — colour-cast check

4. Using this going forward

  1. Print this sheet and the arc-length ladder on the same printer, paper, and print settings — any bias found here should carry over consistently.
  2. Keep this sheet next to the ladder while testing. If you notice a pencil placement looks "wrong" in a way that keeps happening in the same direction (e.g. always reads a bit too dark, or too blue), check whether that matches the bias you noted on the anchor swatches above — a systematic printer shift would explain it, not a placement error.
  3. This is a one-time-ish check, not something to repeat every round — redo it only if you change printer, paper, or print settings.
